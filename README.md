# 📺 TV Remote

基于 ADB 的 Android TV 无线遥控器，浏览器直接控制电视——**按键响应毫秒级，跟手如物理遥控器**。

## ✨ 功能

- **方向键 + OK**，长按自动连续触发
- **返回 / 主页 / 菜单**（菜单键不灵敏时可在设置中开启修复）
- **音量控制**（音量+ / 音量- / 静音）
- **文本输入**：支持中文/emoji/特殊字符，自动同步电视输入框内容，一键替换
- **应用快捷启动**：从已安装应用中选择，自定义名称和图标，一键启动
- **多人同时使用**：所有操作自动排队，互不冲突
- **PWA**：可添加到手机主屏幕，像 App 一样使用
- **中英文自动适配**浏览器语言

## 🚀 快速开始（Docker）

### 1. 电视端准备

进入电视的 **开发者选项**，开启 **USB 调试 / ADB 调试**。首次连接时电视会弹出授权确认，选择"始终允许"。

### 2. 运行容器

```bash
docker run -d \
  --name tv-remote \
  --restart unless-stopped \
  -e ADB_DEVICE=192.168.x.x:5555 \
  -p 8180:8180 \
  ghcr.io/kitdoesit/android-adb-remote:latest
```

把 `192.168.x.x` 换成你电视的 IP 地址。

### 3. 使用

浏览器打开 `http://<运行容器的电脑IP>:8180` 即可开始控制。手机上可"添加到主屏幕"安装为 PWA。

## 🔧 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `ADB_DEVICE` | 无 | 电视地址，如 `192.168.1.100:5555` |
| `PORT` | `8180` | Web 端口 |

## 🛠 自行构建镜像

```bash
git clone <repo-url>
cd android-adb-remote
docker build -t tv-remote .
```
